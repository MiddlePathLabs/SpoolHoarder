Changelog - Recent Updates (May - August 2026)

## Version 26.8.3
[ Features ]
- The inventory assistant now understands the product lines you stock: a typed prompt like "show my Polyterra spools" matches the product families in your inventory instead of falling back to a plain name search.

[ Fixes ]
- Fixed the app's typeface falling back to the system font on Windows, macOS, and Android: four of the five bundled Outfit weights were not valid font files, so almost all text rendered in the platform default instead.
- Deleting a spool no longer erases its usage history on your other devices. A usage log records that filament was consumed on a date, which stays true after the spool is gone.
- Fixed two cloud sync problems that could lose data: an edit saved moments before a sync could be overwritten by an older copy from the server and then look already-synced, and a project deletion that was correctly rejected could still wipe that project's usage logs and filaments on the device receiving it.
- Importing an exported backup no longer skips usage logs that have no unit price recorded on them; those rows used to fail with an error and be silently dropped, so their filament deductions went missing after a restore.
- Fixed reordering favorites moving the wrong spool when a search or a status filter was hiding part of the list.
- Logging usage twice in quick succession - a double tap, or Enter pressed twice - no longer records the usage twice and deducts double.
- Log Usage and Start Project are no longer offered for sold, gifted, or discarded spools in the wide desktop layout, matching the phone layout.
- The Statistics screen no longer drops you back on the Overview tab while its numbers reload.
- Project cost now updates immediately after a reprint, a "Log This Print" from the calculator, or a quick deduction, instead of waiting for something else to refresh it.
- Undoing a sold, gifted, discarded, or used-up spool now checks the free plan's spool limit even after you have navigated away from the screen you started on.
- The reserved Personal Log project can no longer be renamed or turned into an ordinary project by re-importing an exported CSV.
- Account deletion no longer becomes permanently stuck after one failed or timed-out attempt.
- The on-device inventory assistant now asks its own follow-up question when a prompt is ambiguous, instead of pushing you toward the cloud assistant.
- Fixed a signed-in device occasionally reverting the decision about what to do with local data after signing in.
- Fixed Pro access sometimes not loading when opening the app while signed in: an entitlement check racing the sign-in token refresh could leave Statistics and trial messaging on the free plan even with an active Pro subscription or redeemed code, until you restarted the app or restored purchases.
- Fixed Google Play subscription purchases failing to validate, which could keep Pro from activating on Android after a purchase.
- Using a cloud AI feature - spool scan, inventory assistant, or order import - now asks for your explicit consent first, with a clear description of what is sent and to which provider, and you can revoke that consent in Settings at any time. Photos you pick for a scan no longer carry their hidden EXIF metadata, such as the GPS location, out of the app.
- Batch scanning reads unmatched spool labels with AI again instead of coming back unrecognized: local barcode and catalog matches still return instantly, and if the AI scan means sending a photo to the cloud, the app asks for your consent first, once per scan session.
- Typing a hardware barcode on the Add Spool form now prefills empty fields like brand and material when the code is already known from an earlier scan, instead of only saving it for later.
- Moved the NFC scan action on the batch scan screen into the app bar as a labelled button.
- Exports on macOS now open a Save dialog like on Windows instead of the phone-style share sheet, and files shared from the app keep their intended filename instead of a random code.
- Your spool database is encrypted on disk again: a dependency update in March had silently switched the app to an unencrypted database with no error shown. Existing databases are converted to encrypted copies automatically the next time the app starts, and the original unencrypted file is only removed after the conversion has been verified.
- A temporarily unavailable secure-storage key - for example right after an app update - no longer makes the app report a corrupt database, which previously invited a reset that would erase your data; the app now reports the failed launch instead.


## Version 26.8.2
[ Features ]
- Every spool now has a status - active, used up, sold, gifted, or discarded - so a spool that leaves your collection stays a full record instead of being deleted. Mark a spool sold (optionally recording what you received for it and, if it never had one, what you originally paid), gifted, or discarded from its detail screen or the multi-select bar, and bring it back any time with Restore to Inventory.
- Marking a spool used up now prompts you when there is still filament on it, with a one-tap path to mark it discarded instead, and when a usage log takes a spool to exactly zero the app offers to mark it used up for you.
- The inventory filter grew a Status section: a visible "Current inventory" chip is the default view, and clearing it (or picking sold, gifted, discarded, or used up) shows those records. Grouping, cards, rows, and the detail screen all show a spool's status in words, and sold spools without a recorded amount carry a small "No amount" marker so you can fill them in later.
- The free plan's 50-spool limit now counts your current inventory only: sold, gifted, discarded, and used-up records do not take up slots, and restoring a spool back into a full inventory tells you exactly what to do about it.
- Exports now carry each spool's status, exit details, and sale amount through CSV, backups, and cloud sync, and include spools that are no longer in inventory.
- The statistics dashboard gained an exit ledger: totals for spools you have sold, gifted, or discarded, with what your sold spools brought in alongside what they originally cost.

[ Fixes ]
- Undoing a used-up or sold spool restores everything about it - including its remaining weight and printer assignment - instead of leaving some fields behind.
- Statistics no longer flicker or disappear while you are editing a spool; the numbers settle a moment after you stop typing.


## Version 26.8.1
[ Features ]
- Brought multi-currency to the whole app: spool prices, print costs, and reports each carry their own currency, your existing money is migrated automatically, and currencies survive import, export, scanning, and cloud sync. Mixed-currency reports stay correct, with cached exchange rates shown for reference.
- Added language selection: pick the app language in Settings or follow the system, with dates, numbers, and units formatted to your locale.
- Added a complete set of Bambu Lab printer presets.
- Added in-app links to the documentation site from Settings, Contact Us, the inventory error screen, Data & Backup, and Getting Started.
- Added a Weight display setting to track spool weight as filament only or as a total scale reading, with an optional empty-spool weight so the app can convert between the two; existing spools are resolved automatically wherever possible, and you're only asked about the ones it can't determine on its own.
- Added a duplicate action to spool group cards, matching the one already on the spool detail screen.
- Added a Scan button to attach a barcode to a spool from its details card, even if it doesn't have one yet.
- Data exports now include each spool's bound NFC tag UID, so the exported file shows which physical tag opens each spool.
- Added the option to send a one-time support tip to Spool Hoarder from Settings on Android, matching iOS, macOS, and Windows.

[ UI & UX ]
- Redesigned the selected-spool hero with a calmer wound-filament texture that reads as real filament and renders multicolor correctly, and tightened the details, quick-notes, and color-suggestion sections.
- Promoted edit, adjust-weight, and set-location to hero actions on the spool detail screen.
- Decluttered the desktop inventory row: the remaining-weight ring aligns to a fixed trailing column, group headers mirror the rows beneath them, the detail line no longer cuts off mid-token, and summary pills match the row text.
- Lifted navigation contrast so unselected labels and icons read clearly across every palette, fixed the iOS tab bar that bypassed the theme, and restored copy buttons on detail rows.
- Reworked the spool detail screen: wide desktop panes now lead with the color-suggestion strip, the overflow menu moved into a labelled More button, and the details card is a reflowing grid that matches Print Settings.
- Tightened the mobile spool detail layout with a more compact hero and stock ring, a full-width Log Usage action, scroll-aware print profile chips, and quieter "Not set" empty states.
- Added a "TD1 verified" badge to Properties & Features on the spool detail screen when both the transmission distance and color values still hold what a TD1 scan measured.
- Fixed picker sheets, including the barcode scanner, sliding up as full-width phone sheets on desktop windows instead of showing as constrained dialogs.
- Picking a color swatch by family now fills in a name from that family; a custom shade you didn't pick a family for is left unnamed instead of getting an invented name.
- "Find similar" now applies the color filter immediately with an undo option, instead of opening a settings panel over the results, and is now available from group headers as well as individual spools.
- Clarified the two ways to edit a spool: "Quick edit" on the details card edits just those fields, while the full editor is now one tap away on phones via a pencil icon, not just through the overflow menu. Leaving Quick edit with unsaved changes now asks before discarding them.

[ Fixes ]
- Inline spool edits now merge onto the latest stored row instead of overwriting it, so a cloud pull or background update from another device is no longer silently clobbered.
- Library organization moves that fail midway now roll back instead of leaving items half-moved, and organization previews refresh after library changes.
- Made settings restore recoverable when it fails.
- Protected spool-to-location and other relationships during the database rebuild that accompanies the location upgrade.
- Localization fixes across batch-scan currency fields, ISO currency-code spacing, the offscreen share card, and usage-entry parsing.
- Fixed local edits and deletions taking hours to reach other devices instead of syncing right away.
- Fixed duplicate storage locations created on different devices from staying separate forever; merges now converge automatically and keep NFC tag bindings and spool assignments intact.
- Fixed currency exchange rates failing to load for some users; rates now load through a more reliable path with automatic fallback.
- Fixed duplicating a priced spool losing its currency, which could block saving the copy.
- Fixed TD1 verified badges appearing on fields with no actual scanned value.
- Fixed long spool names stretching the More menu off the edge of the screen.
- Fixed the camera scan option being offered on macOS, where camera scanning isn't available.
- Fixed the on-device inventory assistant failing on libraries with a lot of materials, brands, or locations.
- Fixed the mobile spool hero not letting you add a reference photo when none was set.
- Fixed the remaining-weight percentage in the compact inventory row wrapping onto its own line on narrower phones, and made sure it's announced to screen readers in every list style.
- Fixed autocomplete suggestions on the Add Spool form (Brand, Material, Product Family, Purchase Source, Color Description) closing and dismissing the keyboard when you tried to scroll them.
- Fixed inventory grouping merging differently colored spools together when the color came from a swatch, scan, or catalog match rather than typed text.
- Fixed "Show all" not including depleted spools when explicitly requested, and clarified the filter reset button labels.
- Fixed storage locations recreated after being deleted on another device sometimes failing to sync back correctly.
- Fixed the inventory assistant getting stuck instead of showing an error when it couldn't answer a question, and made Clear Filters and back navigation also clear an active search term or assistant-driven view.
- Fixed the on-device inventory assistant not recognizing some materials, brands, or locations that were only recognized when asked online.
- Fixed clearing a field like Brand or Material while reviewing an order import not actually clearing it.
- Fixed a discarded batch scan occasionally having its result reappear afterward.
- Made "Clear All Data" in Settings clearly report whether data was fully or only partially cleared, instead of showing a raw error.
- Fixed location changes from other devices sometimes not appearing promptly on screens already open.
- Fixed an interrupted transmission-distance or color edit sometimes leaving the field marked as NFC-scan-confirmed when the edit hadn't actually been saved.
- Fixed saving a print-cost estimate to a since-deleted project showing an error instead of a clear message.
- Fixed the project cost card showing a saved estimate instead of the actual logged print cost when both were available.
- Fixed inventory value totals skipping currency conversion in some views, which could show incorrect totals for multi-currency libraries.
- Fixed a failed vendor tag lookup being treated as a barcode match, which could point to the wrong product; it's now flagged for manual review instead.
- Fixed hardware barcode scans queued while the app was busy sometimes stalling instead of processing once free.
- Fixed AI order-import credit charges occasionally being double-charged on a network retry.
- Android: purchases that are refunded, cancelled, or revoked on Google Play now lose Pro access right away instead of keeping it until the original period would have ended.
- Fixed the "Add purchase source" prompt jumping the screen around instead of opening cleanly.
- Fixed some Print Settings temperatures showing doubled units, like "215°C°C".
